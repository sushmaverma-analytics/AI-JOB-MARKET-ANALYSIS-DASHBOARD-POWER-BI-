# AI-JOB-MARKET-ANALYSIS-DASHBOARD-POWER-BI-
Power Bi AI job Market dashboard analyzing high demand job, salary, skills, education and hiring patterns using real world dataset.
## 🔍 Key Objectives
- Analyze job demand by role, country, and remote type
- Identify salary trends across experience levels and skill sets
- Understand the impact of skills like Python, SQL, ML, and Cloud on salary
- Track hiring trends over time (Month-over-Month and Year-over-Year growth)

## 🛠️ Tools & Technologies
- PowerQuery (Data cleaning and transforming)
- Dax (Data Modeling and creating relationship)
- Power BI (Data Visualization & Dashboarding)
- 

## 📊 Key Insights
- High demand for roles like Data Analyst, Data Engineer, and AI Engineer
- Remote jobs show significant hiring trends
- Candidates with Python and SQL skills have higher average salaries
- Senior-level professionals dominate high salary categories

## 📁 Dataset Features
- Job Title, Company Size, Industry
- Salary, Experience Level, Education
- Skills (Python, SQL, ML, Deep Learning, Cloud)
- Job Openings and Hiring Urgency
- Posting Month & Year for time analysis

## 🚀 Features Implemented
- KPI Cards (Avg Salary, Total Jobs, Remote Jobs, Total Openings)
- Salary categorization (High vs Low)
- Experience-level segmentation
- Time intelligence (MoM )
- Interactive filters (Country, Date, Experience)

## 💡 Learnings
- Built strong understanding of data modeling and relationships
- Applied DAX for business calculations
- Designed an interactive and insight-driven dashboard
- Improved storytelling using data visualization

## 📌 Conclusion
This project highlights how data analytics can help understand market trends and support better career decisions in the AI industry.
